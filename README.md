# iRyde for desktop

Installers for the iRyde desktop app. The app itself lives at [www.iryde.ai](https://www.iryde.ai).

Download the latest version from [Releases](../../releases/latest):

- **Mac with Apple silicon** (M1 or later): `iRyde-<version>-arm64.dmg`
- **Mac with an Intel processor**: `iRyde-<version>.dmg`

Open the downloaded file and drag iRyde into Applications. The app is signed and notarised by Apple under Virtualco.AI PTY LTD.

This repository holds installers only; it contains no source code.
